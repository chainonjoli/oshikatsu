# 工程3・4:MVP要件定義+機能一覧

## 1. MVPのゴール

King & Prince ファンが、**次のライブ1回分**を「登録 → 準備 → 当日」まで本サービスだけで管理しきれる状態を作る。

## 2. 用語(内部は汎用、表側はK&P向け文言)

| 内部名(汎用) | 表側の見せ方 |
|---|---|
| Oshi(推し) | 「推し」。グループ+メンバー+テーマカラー |
| Event(予定) | 「予定」。ライブ・当落発表・支払期限など |
| Trip(遠征プラン) | 「遠征プラン」 |
| Checklist(持ち物リスト) | 「持ち物リスト」 |
| AffiliateLink | 「おすすめ」(【PR】表記つき) |

## 3. 機能一覧(MVP)

### F1 ユーザー登録・ログイン
- F1-1 メールアドレス+パスワードで登録(パスワードは不可逆ハッシュで保存)
- F1-2 ログイン/ログアウト(Cookieセッション)
- F1-3 未ログイン時は認証ページへ誘導
- F1-4 最初に登録したユーザーを管理者とする(MVP簡易方式。将来は権限管理に置換)

### F2 推し登録
- F2-1 初回セットアップで推しを登録(登録完了までホームに進めない)
- F2-2 標準候補:King & Prince(メンバー名を選択肢として表示)+自由入力
- F2-3 項目:グループ名/メンバー名(=推しの名前)/テーマカラー/ファンになった日/自由メモ
- F2-4 テーマカラーはプリセットパレット+自由選択。アプリ全体のアクセントカラーに反映
- F2-5 推しの編集(設定画面)
- **MVP簡易化(決定)**:推し画像のアップロードはMVPでは行わず、テーマカラー+イニシャルのアバター表示とする(画像保存基盤は将来追加。DB上は画像パス列を予約)
- **権利配慮(決定)**:メンバーカラーの初期値は設定しない。色はユーザー自身が選ぶ(公式設定の転載を避ける)

### F3 推し活カレンダー
- F3-1 月表示カレンダー+当月の予定リスト
- F3-2 予定の登録・編集・削除
- F3-3 項目:タイトル/カテゴリー/日付/開演・開始時間/開場時間/会場/座席/チケット状況/メモ/推し
- F3-4 カテゴリー(14種・色分け):ライブ、舞台、テレビ、ラジオ、雑誌発売、CD/DVD/BD発売、グッズ発売、配信、FC申込期限、チケット申込期限、当落発表、支払期限、ホテルキャンセル期限、その他
- F3-5 期限系カテゴリー(FC申込・チケット申込・支払・キャンセル期限・当落)は警告色で強調
- F3-6 ホーム画面に「直近の期限」を警告表示
- F3-7 チケット状況:申込前/申込済/当選/落選/支払済/発券済/未確認
- 将来拡張:通知(イベントに remind 用の列は持たず、通知テーブルを後付けできるID設計)

### F4 遠征プランナー
- F4-1 遠征プランの作成・編集・削除・一覧
- F4-2 対象の予定(ライブ等)への紐づけ
- F4-3 移動:出発地/交通手段(新幹線・飛行機・高速バス・車・電車・その他)/出発時間/到着予定/帰路メモ
- F4-4 宿泊:ホテル名/チェックイン/チェックアウト/宿泊メモ
- F4-5 予算:交通費/宿泊費/チケット代/グッズ予算/食費/その他 → 合計を自動集計
- F4-6 当日の行動予定(時刻+内容の簡易タイムライン、自由記述行)
- F4-7 宿泊・交通の欄に該当カテゴリーのアフィリエイトリンクを【PR】表記で表示

### F5 持ち物チェックリスト
- F5-1 イベント(予定)ごとにリストを作成・保存
- F5-2 標準テンプレート16項目(チケット、スマホ、モバイルバッテリー、身分証、FC会員証、現金、クレジットカード、交通チケット、ペンライト、うちわ、双眼鏡、タオル、着替え、化粧品、常備薬、雨具)をワンタップ投入
- F5-3 項目の追加・名称編集・削除・チェックON/OFF
- F5-4 達成率表示(◯/◯ 完了)
- F5-5 リスト画面に持ち物系アフィリエイトを【PR】表記で表示

### F6 ライブ当日モード(中心機能)
- F6-1 当日(JST)にライブ/舞台カテゴリーの予定があると、ホーム最上部に当日モードへの大きな導線を表示
- F6-2 表示内容:公演名/開催日/開場・開演時間/会場/座席/チケット状況/持ち物チェック(その場でチェック可)/交通情報/宿泊情報/当日の行動予定/天気(手動メモ+外部天気サイトへのリンク)/推し友メモ(集合場所・時間)/緊急連絡先メモ/自由メモ
- F6-3 未完了警告:チケット未確認・持ち物未チェック・座席未入力などを画面上部に目立つ形で表示
- F6-4 当日以外でも、予定を選んで「当日モードのプレビュー」を確認できる
- F6-5 1画面・縦スクロールのみ。読み込み後の再通信なしで全情報閲覧可

### F7 アフィリエイトリンク管理
- F7-1 管理者のみアクセスできる管理画面
- F7-2 リンクの登録・編集・削除・有効/無効
- F7-3 項目:表示名/URL/カテゴリー(ホテル・交通・持ち物グッズ・CD/雑誌・その他)/説明文/有効フラグ
- F7-4 表示側は常に【PR】ラベルを付ける(ステマ防止)
- F7-5 特定ASP非依存(URLは自由入力)

### F8 スマートフォン対応
- F8-1 375px幅基準のスマホファースト設計、PC でも閲覧可
- F8-2 下部固定ナビ(ホーム/カレンダー/遠征/持ち物/設定)
- F8-3 主要操作ボタンはタップ領域44px以上

## 4. 非機能要件

| 項目 | 要件 |
|---|---|
| 表示速度 | 当日モードは軽量HTML中心。初期表示を最優先 |
| データ | ユーザーのデータは本人のみ閲覧可(全クエリで user_id を必須条件にする) |
| パスワード | scrypt によるハッシュ化。平文保存禁止 |
| セッション | httpOnly Cookie。サーバー側セッションテーブルで失効管理 |
| タイムゾーン | 日付判定はすべて Asia/Tokyo 基準 |
| 拡張性 | 通知・課金プラン・共有・画像保存を後付けできるスキーマ(docs/06) |

## 5. MVPで実装しないことの明示

- グッズ管理/推しノート/推し友共有/AIコンシェルジュ(画面上は「準備中」として存在だけ見せる)
- プッシュ通知・メール通知
- 天気の自動取得(手動メモ+外部リンクで代替)
- 画像アップロード(推し画像・思い出写真)
- パスワード再設定メール(MVPはメール基盤なし。将来追加。**リスクとして明記**)
- 月額課金(users.plan 列だけ先行して用意)
