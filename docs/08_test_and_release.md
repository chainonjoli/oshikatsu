## 4. 起動方法(開発者向け)

```bash
cd web
npm install
npm run dev    # 開発: http://localhost:3000
npm run build && npm start  # 本番ビルド
npm test       # ユニットテスト
```

- 初回アクセスで DB(web/data/app.db)が自動作成される
- **最初に登録したユーザーが管理者**になり、設定 → 運営メニューからアフィリエイトリンクを管理できる
