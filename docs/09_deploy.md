# 公開手順(無料プラン:Vercel + Turso)

このアプリを**無料で**インターネットに公開して、スマホから誰でも使えるようにする手順です。
専門知識がなくても進められるよう、画面操作中心で説明します。

## 全体像

| 役割 | サービス | 料金 |
|---|---|---|
| アプリ本体を動かす | **Vercel**(ヴァーセル) | 無料(Hobbyプラン) |
| データを保存する | **Turso**(ターソ) | 無料枠あり |

どちらも GitHub アカウントで登録できます。クレジットカードは不要です(2026年時点・**推定**。登録画面で最新の条件を確認してください)。

> ⚠️ **商用利用の注意**:Vercel の無料(Hobby)プランは非商用利用が条件です。友人・知人へのテスト公開は問題ありませんが、**アフィリエイトで収益を得る運用を始める段階では Vercel Pro(月$20前後)への変更、または他のホスティングが必要**です。

## 手順1:Turso でデータベースを作る(5分)

1. https://turso.tech を開き、「Sign Up」→ GitHub でログイン
2. ダッシュボードで「Create Database」→ 名前は `oshikatsu` など → ロケーションは東京(nrt)があれば選択 → 作成
3. 作成したデータベースの画面で次の2つをメモする:
   - **URL**(`libsql://〜.turso.io` の形)
   - **Auth Token**(「Create Token」等のボタンで発行される長い文字列)

## 手順2:Vercel にアプリを載せる(10分)

1. https://vercel.com を開き、「Sign Up」→「Continue with GitHub」
2. 「Add New...」→「Project」→ リポジトリ一覧から `chainonjoli/oshikatsu` の「Import」を押す
3. 設定画面で次の2か所を設定:
   - **Root Directory**:「Edit」を押して `web` を選択(重要!)
   - **Environment Variables**:次の2つを追加
     | Name | Value |
     |---|---|
     | `DATABASE_URL` | 手順1でメモした URL(libsql://〜) |
     | `DATABASE_AUTH_TOKEN` | 手順1でメモした Auth Token |
4. 「Deploy」を押して数分待つ
5. 完了画面に **`https://〜.vercel.app`** のURLが表示されます。これが「みんなが使えるURL」です

## 手順3:最初のアカウントを自分で登録する(1分)

⚠️ 重要:**最初に登録したユーザーが管理者**になります。
URLが発行されたら、**他の人に教える前に必ずご自身で最初の登録**を済ませてください。
(管理者は 設定 → 運営メニュー からアフィリエイトリンクを管理できます)

## 更新方法

GitHub の `main` ブランチが更新されると、Vercel が自動で再デプロイします。データは Turso 側にあるので消えません。

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| ビルドエラーになる | Root Directory が `web` になっているか確認 |
| 開くとサーバーエラー | 環境変数2つ(DATABASE_URL / DATABASE_AUTH_TOKEN)の値を確認。変更後は「Redeploy」 |
| ログインしてもすぐログアウトされる | URLを `https://` で開いているか確認 |

エラー画面の内容をそのまま伝えていただければ、こちらで原因を調べます。

## ローカル開発(参考)

開発時は環境変数なしで従来どおり動きます(`web/data/app.db` にファイル保存)。
`cd web && npm run dev` → http://localhost:3000

## 公開前に必ず確認すること

`docs/08_test_and_release.md` のチェックリストのうち、特に以下は「友人・知人でのテスト公開」を超えて広く告知する前に済ませてください。

1. **利用規約・プライバシーポリシーの掲載**(メールアドレスや予定を預かるため)
2. **問い合わせ先の明示**(パスワードを忘れた人への対応窓口。再設定メール機能は未実装)
3. **正式なサービス名の決定**(現在は仮称)
4. **Vercel Pro への変更**(アフィリエイト収益化を始める場合)
5. **データのバックアップ**(Turso のダンプ機能または定期エクスポート)

## ほかの選択肢(参考)

Docker 対応のホスティング(Railway・Fly.io・VPS等)なら、同梱の `web/Dockerfile` でそのまま動きます(その場合は環境変数なしでファイルSQLiteが使われるため、永続ディスクを `/app/data` にマウントしてください)。
