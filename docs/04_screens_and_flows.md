## 2. ユーザー導線

### 導線A:初回利用(目標3分)
```
/register(メール+パスワード)
→ /setup(推し登録:K&P候補から選択 or 自由入力 → カラー選択)
→ /(ホーム。空状態ガイド「最初の予定を登録しましょう」)
```

### 導線B:ライブが決まってから当日まで(コア導線)
```
① 予定登録    /events/new(カテゴリー=ライブ、会場・開演時間)
② 期限も登録   当落発表日・支払期限(ホームに警告が出るようになる)
③ 遠征計画    /trips/new(予定に紐づけ → 交通・宿泊・予算 → 合計自動表示)
                └ 宿泊・交通欄に【PR】リンク
④ 持ち物準備   /checklists(テンプレ投入 → 編集 → チェック)
                └ 【PR】持ち物リンク
⑤ 当日       ホーム最上部「ライブ当日モード」→ /today
                └ 全情報1画面+未完了警告
```

### 導線C:日常利用(数十秒)
```
/(ホーム)
→ 次のイベントカウントダウン/直近の期限警告/今日の予定 を確認して閉じる
```

```
│ ● あかり さんの推し活          [設定⚙] │  ← 推しカラーのヘッダー
│ ♥ 推し名(グループ名)                  │

├──────────────────────────┤
│ 🎤 今日はライブ当日!                   │  ← 当日のみ表示・最上部・大

├──────────────────────────┤
│ ⚠ 直近の期限                           │  ← 期限系カテゴリーの7日以内
│ ・7/31 支払期限「〇〇ツアー」           │     未来分を警告色で表示
├──────────────────────────┤

│ ・8/10(土) 18:00 ライブ 東京ドーム      │
├──────────────────────────┤
│ [今日の予定]   [当日モード]             │  ← 大きい2列ボタン
```

### S09 遠征プラン作成・編集
```
基本情報: プラン名 / 紐づける予定(選択) / 出発地
移動:    交通手段 / 出発時間 / 到着予定 / 帰路メモ
          └ 【PR】新幹線・航空券・バスの予約はこちら
宿泊:    ホテル名 / チェックイン / チェックアウト / メモ
          └ 【PR】ホテル予約はこちら
予算:    交通費 / 宿泊費 / チケット代 / グッズ / 食費 / その他
          ▶ 合計 ¥◯◯,◯◯◯(自動計算・常時表示)
行動予定: [時刻][内容] の行を自由に追加
```

