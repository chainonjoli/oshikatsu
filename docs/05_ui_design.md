# 工程8:UIデザイン方針・デザイントークン

## 1. デザインコンセプト

**「上品で明るい、大人の推し活手帳」**

- 明るく華やかだが、子どもっぽくしない(パステル+白基調、装飾は最小限)
- 推しのテーマカラーがアプリ全体のアクセントになる(ヘッダー・ボタン・強調)
- 当日モードは「安心感」重視:大きい文字、はっきりした警告、迷わない縦一列

## 2. デザイントークン

### カラー
| トークン | 値 | 用途 |
|---|---|---|
| `--color-accent` | 推しテーマカラー(動的) | ヘッダー、主ボタン、強調 |
| `--color-bg` | `#FAF7F5`(温かみのある白) | 背景 |
| `--color-surface` | `#FFFFFF` | カード |
| `--color-text` | `#3D3A3E` | 本文(真っ黒を避ける) |
| `--color-muted` | `#8E8A92` | 補助テキスト |
| `--color-warning` | `#E5484D` | 期限警告・未完了 |
| `--color-warning-bg` | `#FFF0F0` | 警告背景 |
| `--color-ok` | `#30A46C` | 完了・チェック済 |

### 推しテーマカラーパレット(ユーザー選択式・初期値なし)
赤 `#E5484D` / ピンク `#E93D82` / オレンジ `#F76B15` / 黄 `#FFC53D` / 緑 `#30A46C` / 水色 `#00A2C7` / 青 `#3E63DD` / 紫 `#8E4EC6` / 白系 `#B8A9C9`(白は視認性のため薄紫で代替) / 黒系 `#3D3A3E`
※権利配慮のため「◯◯くんの色」という提示はせず、色名のみで提示する。

### カテゴリーカラー(カレンダー)
| 系統 | カテゴリー | 色 |
|---|---|---|
| 公演系 | ライブ/舞台 | 推しアクセント系(濃) |
| メディア系 | テレビ/ラジオ/配信 | 青系 |
| 発売系 | 雑誌/CD・DVD/グッズ | 緑〜黄系 |
| **期限系** | FC申込/チケット申込/当落/支払/キャンセル期限 | **警告赤(統一)** |
| その他 | その他 | グレー |

### タイポグラフィ・寸法
- フォント:システムフォント(`system-ui`)。日本語はOS標準で十分読みやすく、軽い
- 基本文字 16px / 見出し 20〜24px / 補助 13px
- タップ領域:最小 44×44px。主要ボタンは高さ 52px
- 角丸 12〜16px、影は薄く1段のみ
- 余白:カード内 16px、セクション間 24px

## 3. コンポーネント方針

| コンポーネント | 方針 |
|---|---|
| 下部ナビ | 5項目固定・アイコン+短いラベル・現在地をアクセント色 |
| カード | 白背景+薄影。1情報1カード |
| 警告バナー | 警告背景+左ボーダー赤+太字。当日モードとホームで共通 |
| バッジ | カテゴリー色の小ラベル。「準備中」はグレー |
| 【PR】ブロック | 枠線+「PR」ラベルを左上に固定表示。本文と明確に区別 |
| フォーム | 1画面1目的。ラベル上置き・入力欄大きめ・数字はテンキー起動(`inputmode`) |

## 4. アクセシビリティ・操作性

- 片手操作:主要アクションは画面下半分に配置(送信ボタン・FAB)
- コントラスト:本文 4.5:1 以上。アクセント色の上の文字は白/黒を自動判定
- 文言:専門用語を避ける(例:「認証」→「ログイン」、「サブミット」→「保存する」)
