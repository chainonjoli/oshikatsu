# 工程2:競合との差別化整理

> 注:競合の機能・傾向は一般に公開されている情報にもとづく **推定** を含む(2026年時点の網羅的な調査ではない)。公開前に最新の競合状況を再確認すること。

## 1. 競合のカテゴリー分け

推し活ユーザーが現在使っているツールは、大きく5種類に分かれる。

| カテゴリー | 代表例(推定) | ユーザーがしていること |
|---|---|---|
| A. 汎用カレンダー | iPhone標準カレンダー、Googleカレンダー | ライブ日程・発売日の登録 |
| B. 汎用メモ | iPhoneメモ、LINE Keep | 持ち物リスト、座席メモ |
| C. 旅行予約・管理 | 楽天トラベル、じゃらん、各交通アプリ | ホテル・新幹線の予約と確認 |
| D. SNS | X(旧Twitter)、Instagram | 情報収集、感想の投稿 |
| E. 推し活特化アプリ | 推し活手帳系・オタ活記録系アプリ(複数存在すると推定) | 記録、費用管理など一部機能 |

## 3. 核心的な差別化:「当日の1画面」

- 既存ツールは「登録する場所」「予約する場所」「調べる場所」であり、**「当日に開く場所」がない**。
- 本サービスは、①〜⑤の準備フェーズで入力された情報が、⑥当日に「ライブ当日モード」として自動で1画面に集約される。**準備が当日の安心に変わる**ことが独自価値。
- 推し活特化アプリ(E)は「記録・費用管理」寄りが多く(推定)、遠征・当日動線まで一気通貫で支えるものは見当たらない(推定)。

## 4. 差別化を支える3つの設計原則

1. **当日ファースト**:すべての機能は「当日モードに情報が流れ込む」ことを前提に設計する
2. **テンプレートファースト**:入力の手間を最小化(持ち物テンプレート、予定カテゴリー、遠征のひな形)
3. **K&Pファン文脈への特化(表側)**:予定カテゴリー名・持ち物項目・文言をジャニーズ系ライブ文化(FC抽選→当落→支払、うちわ・ペンライト等)に合わせる。内部データは汎用

## 5. 競合に対する弱み(正直な評価)と対処

| 弱み | 対処 |
|---|---|
| 標準カレンダーの「通知」がMVPにない | 期限系はホーム画面で常時警告表示。通知は早期に追加 |
| 予約機能そのものはない(旅行系に勝てない) | 予約は外部サイトに任せ、「予約情報の一元管理+導線(アフィリエイト)」に徹する |
| 新規アプリは入力済みデータがゼロ | 初回セットアップを3分以内に。テンプレートで最初の価値をすぐ体験させる |
